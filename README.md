# 神话风（shenhua）技能包

纯代码（Python + cairocffi + numpy）制作“壁画剪纸木偶”风格的神话短片：无旁白、中文大字幕、合成异域配乐。

- 技能说明：[`SKILL.md`](SKILL.md)（给 AI 账号学习用，按里面的规范和流程做）
- 参考视频：`参考视频/` 里有对标片和样片各 10 秒
- 最新工程：`希腊引擎/`（百眼巨人阿耳戈斯，233 秒）；北欧范例：`北欧范例/`

依赖：`pip install numpy opencv-python-headless cairocffi Pillow soundfile scipy`，以及 ffmpeg。
